feat: Adiciona sistema de anotações múltiplas para orçamentos

Implementa funcionalidade que permite criar múltiplas linhas de orçamento
para a mesma subcategoria e ano, cada uma com suas próprias anotações,
permitindo comentários explicativos para diferentes conjuntos de valores.

- Adiciona campo `notes` (TextField) ao modelo Budget para armazenar anotações
- Remove constraint `unique_together` de (subcategory, budget_date) para permitir
  múltiplos orçamentos por subcategoria/mês com anotações diferentes
- Adiciona índice composto em (subcategory, budget_date, notes) para otimização
- Cria migrações 0032 (add notes field) e 0033 (remove unique_together)
