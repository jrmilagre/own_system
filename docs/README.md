# Documentação do Projeto

Este diretório contém documentação técnica do projeto.

## Documentos Disponíveis

### [TEMPLATE_STANDARDS.md](./TEMPLATE_STANDARDS.md)
Padrão de templates para filtros e tabelas baseado no template de transações. Inclui:
- Estrutura de filtros com dropdowns e checkboxes
- Tabelas com ordenação múltipla
- Estilos CSS padrão
- JavaScript padrão
- Formulários e views Django
- Boas práticas e checklist

**Use este documento como referência ao criar novos templates de listagem.**

---

## Como Usar

1. **Para criar um novo template de listagem:**
   - Consulte `TEMPLATE_STANDARDS.md`
   - Siga a estrutura e padrões definidos
   - Use o checklist fornecido para garantir completude

2. **Para atualizar padrões:**
   - Edite `TEMPLATE_STANDARDS.md`
   - Mantenha exemplos atualizados
   - Documente mudanças significativas
